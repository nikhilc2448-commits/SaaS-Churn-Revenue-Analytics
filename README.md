# SaaS Churn & Revenue Analytics Platform

A one-week end-to-end data analytics project built using **Python, SQL, Excel, and Power BI** to analyze customer churn, monthly recurring revenue (MRR), customer retention, and business performance.

## 📌 Project Overview

CloudMetrics is a B2B SaaS company facing declining revenue growth due to customer churn. This project analyzes four business datasets to identify churn patterns, calculate key KPIs, segment customers, and present actionable insights through interactive dashboards.

## 🛠️ Tech Stack

- **Python:** Pandas, NumPy, Matplotlib, SciPy, Scikit-learn
- **SQL:** MySQL
- **Excel:** Pivot Tables & KPI Reporting
- **Power BI:** Interactive Dashboard
- **Git & GitHub**

## 📊 Key KPIs

| KPI | Value |
|------|------:|
| Total Customers | 420 |
| Churned Customers | 109 |
| Churn Rate | 25.95% |
| Total MRR | 269.93K |
| Average Revenue per Account | 642.69 |

## 📈 Power BI Dashboard

The dashboard includes:

- KPI Cards
- Revenue by Industry
- Revenue by Plan
- Customer Acquisition Channel
- Ticket Priority Distribution
- Customer Satisfaction Analysis
- Interactive Slicers (Industry, Country, Plan, Status)

## ▶️ How to Run

1. Clone this repository.
2. Install the required Python libraries.
3. Place the four CSV files inside the `datasets` folder.
4. Run the Python modules from **Module 01** to **Module 09**.
5. Execute the SQL script in MySQL.
6. Open the `.pbix` file in Power BI Desktop to view the dashboard.
